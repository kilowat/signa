Signa

Лёгкая обёртка над Web Components, uhtml и @preact/signals-core. Для обычных HTML и PHP сайтов — без сборки на странице. ~20kb min / ~8kb gzip.

Возможности

  • Одна функция sig() — компоненты, стейт, composable
  • HTML-шаблоны на базе uhtml
  • Реактивность через @preact/signals-core
  • State: синглтон и composable
  • Bus для общения компонентов
  • Хэш-роутер

Быстрый старт

На window появляется одна функция sig():

Компоненты

id содержит дефис → компонент. Функция setup получает контекст и должна вернуть функцию-рендер.

Контекст компонента

Ключ Описание
$this HTMLElement инстанс
html uhtml тег-шаблон
signal(val) Реактивное значение
computed(fn) Вычисляемое значение
effect(fn) Сайд-эффект, вернуть fn для cleanup
prop(name, Type?, default?) Read-only проп
slot / slot('name') Слотированный контент
state(key) Получить инстанс стейта
bus Event bus

Props

Props — read-only внутри компонента. Позиционные аргументы: имя, тип, дефолт.

Slots

State

id без дефиса → стейт. Возвращает объект — синглтон, возвращает функцию — composable.

Bus

bus.on возвращает функцию отписки. Используй внутри effect — очистится автоматически при размонтировании компонента.

Роутинг

Хэш-роутер. Создаётся через sig.router(), удобно хранить в стейте.

PHP интеграция

sig(key) с одним аргументом возвращает инстанс стейта. Инстанс создаётся лениво при первом вызове, поэтому можно писать в него до монтирования компонентов.
